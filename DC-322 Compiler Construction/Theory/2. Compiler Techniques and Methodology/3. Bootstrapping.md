## 2.3 Bootstrapping

### Definition

**Bootstrapping** is the process of **writing a compiler for a programming language in the same language** that it compiles.

---

### Why Bootstrapping Is Needed

* To prove language completeness
* To improve compiler quality
* To make the compiler self-hosting

---

### Bootstrapping Process (Step-by-Step)

1. **Initial Compiler**

   * Write a simple compiler in an existing language (e.g., C)

2. **Compile New Compiler**

   * Use the initial compiler to compile a more advanced version written in the target language

3. **Self-Hosting**

   * Compiler compiles its own source code

---

### Example (C Language)

1. First C compiler written in **assembly**
2. Later versions written in **C**
3. Modern C compilers compile themselves

---

### Visual Flow

```
Compiler v1 (in C)
     ↓
Compiles Compiler v2 (written in target language)
     ↓
Compiler v2 becomes self-hosting
```

---

### Advantages of Bootstrapping

* Language maturity validation
* Performance improvement
* Easier maintenance

---

### Exam Tip

> “Bootstrapping proves that a language is powerful enough to define its own compiler.”
