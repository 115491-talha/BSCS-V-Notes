## 2.2 Compiler Construction Approaches

These approaches describe **how a compiler is implemented** from an engineering perspective.

---

### 2.2.1 Single-Pass Compiler

**Definition**
A compiler that processes the source program **only once**.

**Characteristics**

* Fast compilation
* Limited language features
* Minimal memory usage

**Limitations**

* Hard to support:

  * Forward declarations
  * Complex optimizations

**Example**

* Early Pascal compilers
* Simple assemblers

---

### 2.2.2 Multi-Pass Compiler

**Definition**
A compiler that processes the source program **multiple times**, each pass performing a specific task.

**Typical Passes**

1. Syntax and semantic checks
2. Intermediate code generation
3. Optimization
4. Code generation

**Advantages**

* Better optimization
* Supports complex languages

**Example**

* GCC
* Clang

---

### 2.2.3 Load-and-Go Compiler

**Definition**
A compiler that **generates code and executes it immediately**, without producing an object file.

**Characteristics**

* No storage of object code
* Faster turnaround

**Disadvantage**

* Program must be recompiled every run

**Use Case**

* Educational compilers
* Debug environments

---

### 2.2.4 Cross Compiler

**Definition**
A compiler that runs on **one machine** but generates code for **another machine**.

**Example**

* ARM cross-compiler running on x86
* Embedded systems development

```
Host Machine ≠ Target Machine
```
