## 2.4 Retargetable Compilers

### Definition

A **retargetable compiler** is a compiler designed so that it can be **easily adapted to generate code for different target machines** with minimal changes.

---

### Key Idea

Change **only the back end**, keep the front end unchanged.

---

### How Retargetability Is Achieved

1. Intermediate Representation (IR)
2. Machine description files
3. Modular back-end design

---

### Architecture

```
Source Language
     ↓
Language-Specific Front End
     ↓
Intermediate Representation (IR)
     ↓
Machine-Specific Back End
     ↓
Target Code
```

---

### Example

* **LLVM**

  * Same IR
  * Back ends for x86, ARM, RISC-V

* **GCC**

  * Supports dozens of architectures

---

### Benefits

* Portability
* Faster support for new hardware
* Reduced development cost

---

### Real-World Relevance

* Mobile processors
* Embedded systems
* Cloud platforms
