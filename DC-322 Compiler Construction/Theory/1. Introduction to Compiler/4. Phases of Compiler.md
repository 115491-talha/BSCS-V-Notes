# 1. Introduction to Compiler

---

## 1.4 Phases of a Compiler

A compiler works in **multiple well-defined phases**, each performing a specific task.

### High-Level View

```
Source Code
   ↓
Lexical Analysis
   ↓
Syntax Analysis
   ↓
Semantic Analysis
   ↓
Intermediate Code Generation
   ↓
Code Optimization
   ↓
Target Code Generation
```

---

### 1.4.1 Lexical Analysis (Scanner)

**Purpose**

* Converts character stream into **tokens**

**Examples of Tokens**

* Keywords (`int`, `if`)
* Identifiers (`sum`, `count`)
* Operators (`+`, `=`)
* Literals (`10`, `3.14`)

**Example**

```c
int x = 10;
```

Tokens:

```
<int> <id,x> <=> <num,10> <;>
```

---

### 1.4.2 Syntax Analysis (Parser)

**Purpose**

* Checks **grammatical structure**
* Builds **parse tree / syntax tree**

**Detects Errors Like**

```c
int x = ;
```

**Example**
Expression:

```
a + b * c
```

Parse tree ensures:

```
b * c evaluated first
```

---

### 1.4.3 Semantic Analysis

**Purpose**

* Checks **meaning**, not structure
* Ensures type correctness and declarations

**Examples**

```c
int x;
x = "hello";   ❌ type mismatch
```

Checks include:

* Variable declared before use
* Type compatibility
* Function argument matching

---

### 1.4.4 Intermediate Code Generation

**Purpose**

* Converts source code into **machine-independent intermediate form**

**Common Forms**

* Three-Address Code
* Quadruples
* Triples

**Example**
Expression:

```
a = b + c * d
```

Three-address code:

```
t1 = c * d
t2 = b + t1
a  = t2
```

---

### 1.4.5 Code Optimization

**Purpose**

* Improves performance without changing meaning

**Types**

* Dead code elimination
* Constant folding
* Loop optimization

**Example**
Before:

```
x = 3 * 4;
```

After:

```
x = 12;
```

---

### 1.4.6 Target Code Generation

**Purpose**

* Converts optimized intermediate code into **machine code**

**Output**

* Assembly code
* Object file
* Executable
