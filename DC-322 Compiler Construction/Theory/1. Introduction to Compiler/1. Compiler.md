# 1. Introduction to Compiler

---

## 1.1 Definition of Compiler

### Definition

A **compiler** is a system program that **translates a high-level source program** written in one programming language (called *source language*) into an **equivalent low-level program** (called *target language*, usually machine code or assembly), **before execution**.

### Key Characteristics

* Translation happens **once**, not every time the program runs
* Produces an **object/executable file**
* Detects **syntax and semantic errors** during compilation
* Output program executes **faster** than interpreted code

### Formal View

```
Source Program (High-level) → Compiler → Target Program (Machine-level)
```

### Example

Source code (C):

```c
int sum = a + b;
```

After compilation:

* Converted into **machine instructions**
* Stored as `.exe` or binary
* Executed directly by CPU

### Real-Life Analogy

Think of a compiler like **translating a book**:

* You translate once
* Print the translated book
* Anyone can read it without needing the translator again
