## 1.2 Definition of Interpreter

### Definition

An **interpreter** is a program that **reads, translates, and executes** a source program **line-by-line**, **at runtime**, without producing a separate executable file.

### Key Characteristics

* Translation and execution happen **simultaneously**
* No permanent target code is generated
* Stops execution **immediately on first error**
* Generally **slower** than compiled programs

### Execution Flow

```
Source Code → Interpreter → Immediate Execution
```

### Example

Python code:

```python
print(a + b)
```

* Python interpreter reads the line
* Converts it internally
* Executes it instantly

### Real-Life Analogy

An interpreter is like a **live translator**:

* Translates sentence by sentence
* If you stop speaking, translation stops
* Must be present every time
