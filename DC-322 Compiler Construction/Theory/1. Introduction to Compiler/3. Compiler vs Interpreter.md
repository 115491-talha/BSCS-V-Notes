## 1.3 Compiler vs Interpreter

| Aspect          | Compiler                     | Interpreter                 |
| --------------- | ---------------------------- | --------------------------- |
| Translation     | Entire program at once       | Line by line                |
| Output          | Generates executable         | No executable               |
| Execution Speed | Fast                         | Slower                      |
| Error Handling  | Reports all errors together  | Stops at first error        |
| Memory          | More (stores object code)    | Less                        |
| Reusability     | Compile once, run many times | Needs interpreter every run |
| Examples        | C, C++, Java (partially)     | Python, JavaScript, Ruby    |

### Hybrid Example (Important for Exams)

* **Java** uses both:

  * Compiler → Bytecode
  * Interpreter/JIT → Execution
