# 1. Introduction to Compiler

---

## 1.5 Language Processing System

### Definition

A **Language Processing System** is a collection of programs that **translate, optimize, and execute programs written in high-level languages**.

### Components

1. **Preprocessor**
2. **Compiler**
3. **Assembler**
4. **Linker**
5. **Loader**

---

### Flow of Language Processing System

```
Source Program
   ↓
Preprocessor
   ↓
Compiler
   ↓
Assembler
   ↓
Linker
   ↓
Loader → Execution
```

---

### 1.5.1 Preprocessor

Handles:

* Macro expansion (`#define`)
* File inclusion (`#include`)
* Conditional compilation

Example:

```c
#define PI 3.14
```

---

### 1.5.2 Assembler

* Converts **assembly language** into **machine code**

Example:

```
MOV AX, BX
```

↓

Binary instructions

---

### 1.5.3 Linker

* Combines multiple object files
* Resolves function calls and variables

Example:

* `main.o` + `math.o` → final executable

---

### 1.5.4 Loader

* Loads executable into memory
* Assigns addresses
* Starts execution
