## Topic: Database

### **Definition**

A database is an organized collection of related data stored electronically in a structured format, designed to be easily accessed, managed, and updated.

---

### **Explanation**

A database stores data in a systematic way so that:

* Data can be **retrieved efficiently**
* Redundancy is **minimized**
* Consistency and integrity are **maintained**
* Multiple users can **access data concurrently**

In modern systems, data is usually organized in **tables (relations)** consisting of rows (records) and columns (attributes). The database itself does not perform operations; it is managed by a **Database Management System (DBMS)**.

---

### **Key Characteristics of a Database**

* **Structured storage** (tables, schemas)
* **Related data** (not random files)
* **Persistent** (data survives system restarts)
* **Shared access** (multi-user environment)
* **Controlled access** (security and constraints)

---

### **Real-Life Example**

A **university database** may store:

* Student information
* Course details
* Enrollment records
* Exam results

Instead of keeping separate files for students, courses, and results, all related data is stored centrally and linked using keys (e.g., Student ID).

---

### **Database vs Simple Data Storage**

| Aspect            | Database       | Simple File Storage |
| ----------------- | -------------- | ------------------- |
| Organization      | Structured     | Unstructured        |
| Redundancy        | Low            | High                |
| Data Integrity    | Enforced       | Not enforced        |
| Multi-User Access | Supported      | Limited             |
| Query Support     | Powerful (SQL) | Manual              |

---

### **Why Databases Are Important**

* Support **decision making**
* Enable **large-scale applications**
* Ensure **data accuracy and consistency**
* Allow **fast searching and reporting**

---

### **Exam-Friendly Definition (One-Line)**

> A database is a structured and organized collection of related data stored for efficient access and management.
