## Topic: Data & Information

### **Data**

**Definition:**
Data refers to raw, unprocessed facts and figures that by themselves have little or no meaningful context.

**Explanation:**
Data is simply recorded observations or values. It may be numbers, text, symbols, or measurements, but it does not convey any understanding until it is processed. Data is typically the **input** to a database system.

**Real-Life Example:**

* Student roll number: `1023`
* Marks: `85`
* Date: `12-06-2025`

Individually, these values do not explain anything.

---

### **Information**

**Definition:**
Information is processed, organized, and structured data that is meaningful and useful for decision-making.

**Explanation:**
When data is interpreted and given context, it becomes information. In DBMS, information is usually produced by **queries, reports, or calculations** performed on stored data.

**Real-Life Example:**

* “Student with roll number 1023 scored 85 marks in Database Systems on 12-06-2025.”

This statement provides meaning and can be used for decisions (grading, ranking, promotion).

---

### **Relationship Between Data and Information**

| Aspect     | Data             | Information           |
| ---------- | ---------------- | --------------------- |
| Nature     | Raw facts        | Processed meaning     |
| Context    | Lacks context    | Has context           |
| Usefulness | Limited          | Useful for decisions  |
| DBMS Role  | Stored in tables | Retrieved via queries |

---

### **Why This Distinction Matters in DBMS**

* Databases **store data**, not information.
* DBMS **processes data** to generate information.
* Queries (`SELECT`, `JOIN`, `GROUP BY`) are the tools that transform data into information.
* Decision-making systems rely on **information**, not raw data.

---

### **Short Exam-Friendly Line (Optional)**

> Data is raw input, while information is meaningful output produced after processing data.
