## Topic: File System

### **Definition**

A file system is a method of storing and organizing data in files on a storage device, where each file is managed and accessed by application programs.

---

### **Explanation**

In a file system:

* Data is stored in **separate files**
* Each application defines its **own file format**
* The operating system provides basic file operations (read, write, delete)
* There is **no centralized control** over data consistency or redundancy

Programs interact **directly with files**, not through a management layer like a DBMS.

---

### **Key Characteristics of a File System**

* Application-dependent data structure
* No built-in support for relationships between data
* Limited security mechanisms
* Manual enforcement of data integrity
* Difficult to share data among multiple applications

---

### **Real-Life Example**

A college maintains:

* One Excel file for student details
* Another file for course records
* A separate file for exam results

If a student changes their name, it must be updated **manually in all files**, increasing the chance of inconsistency.

---

### **Limitations of File System**

* **Data redundancy** – same data stored in multiple files
* **Data inconsistency** – mismatched values across files
* **Difficult data access** – complex queries require custom code
* **Poor security** – limited access control
* **No concurrency control** – multi-user conflicts possible

---

### **File System vs DBMS (Preview)**

| Aspect            | File System    | DBMS                 |
| ----------------- | -------------- | -------------------- |
| Data Storage      | Separate files | Centralized database |
| Redundancy        | High           | Low                  |
| Integrity         | Manual         | Enforced             |
| Query Support     | Limited        | Powerful (SQL)       |
| Multi-User Access | Weak           | Strong               |

---

### **Exam-Friendly One-Liner**

> A file system stores data in separate files managed by applications without centralized control.
