## 1. Basics of Operating System

### Short Question

**Q1. What are the basics of an operating system?**
**Answer:**
The basics of an operating system include resource management, process control, memory management, I/O handling, and providing an execution environment for programs.

### Short Question

**Q2. What is the role of an OS in computer system operation?**
**Answer:**
The OS controls and coordinates the use of hardware among application programs to ensure correct and efficient system operation.

## 2. Basic Structure of a Computer System

### Short Question

**Q3. What are the main components of a computer system?**
**Answer:**
A computer system consists of hardware (CPU, memory, I/O devices), operating system, application programs, and users.

### Long Question

**Q4. Explain the basic structure of a computer system.**
**Answer:**
A computer system is organized into four major components:

* **Hardware:**
  Includes the CPU, main memory, and input/output devices. It provides the basic computing resources.

* **Operating System:**
  Acts as a resource manager and intermediary between hardware and users. It controls program execution and resource allocation.

* **Application Programs:**
  Programs such as compilers, browsers, and databases that use OS services to perform user tasks.

* **Users:**
  People or other systems that interact with the computer.

The operating system plays a central role by coordinating hardware usage and providing services to applications.

## 3. Central Processing Unit (CPU)

### Short Question

**Q5. What is the CPU?**
**Answer:**
The CPU is the primary component of a computer system that executes instructions and performs arithmetic and logical operations.

### Short Question

**Q6. What are the main parts of the CPU?**
**Answer:**
The main parts of the CPU are the Arithmetic Logic Unit (ALU), Control Unit (CU), and registers.

## 4. Device Controllers and Memory Controller

### Short Question

**Q7. What is a device controller?**
**Answer:**
A device controller is a hardware component that manages a specific I/O device and communicates with the operating system.

### Short Question

**Q8. What is the function of a memory controller?**
**Answer:**
The memory controller manages communication between the CPU and main memory, controlling read and write operations.

### Long Question

**Q9. Explain device controllers and memory controllers in a computer system.**
**Answer:**
Device controllers are specialized hardware units responsible for controlling particular I/O devices such as disks, keyboards, and printers. Each controller has local buffers and registers and operates independently of the CPU.

The **memory controller** manages access to main memory. It ensures correct data transfer between the CPU and RAM, handles memory timing, and supports efficient memory access.

Both controllers reduce CPU workload by handling low-level hardware operations and enabling parallelism in system operation.

## 5. Bootstrap Program

### Short Question

**Q10. What is a bootstrap program?**
**Answer:**
A bootstrap program is a small program stored in firmware that initializes hardware and loads the operating system into memory during system startup.

### Short Question

**Q11. Where is the bootstrap program stored?**
**Answer:**
The bootstrap program is stored in non-volatile memory such as ROM or firmware.

### Long Question

**Q12. Explain the working of a bootstrap program.**
**Answer:**
When a computer is powered on, the bootstrap program is the first code executed. It performs system initialization, including hardware checks, and locates the operating system kernel on secondary storage.

Once located, the bootstrap program loads the kernel into main memory and transfers control to it. This process allows the operating system to begin execution and manage the system.

## 6. Interrupts and System Calls

### Short Question

**Q13. What is an interrupt?**
**Answer:**
An interrupt is a signal that temporarily halts the CPU’s current execution to handle an event such as I/O completion or hardware failure.

### Short Question

**Q14. What is a system call?**
**Answer:**
A system call is a mechanism that allows user programs to request services from the operating system.

### Short Question

**Q15. How are interrupts different from system calls?**
**Answer:**
Interrupts are generated by hardware or software events, while system calls are explicitly invoked by user programs to access OS services.

### Long Question

**Q16. Explain interrupts and system calls in operating systems.**
**Answer:**
**Interrupts** are used to signal the CPU that an event requiring attention has occurred. When an interrupt happens, the CPU saves its current state and transfers control to an interrupt service routine.

**System calls** provide a controlled interface between user programs and the operating system. They allow applications to request services such as file access, process creation, and I/O operations.

Together, interrupts and system calls enable efficient interaction between hardware, operating system, and user programs while maintaining system protection.
